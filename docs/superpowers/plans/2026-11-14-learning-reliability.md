# 题库可靠性与学习功能实施计划

**目标：** 保留现有个人题库与数据，修复编辑、导入、判分和组卷一致性，增加专项练习、间隔复习、可保存考试及完整备份。

**实现约束：** 主会话与所有子代理仅用 `gpt-6-astra`；按用户追加授权创建公共仓库所需的独立根提交，保留本地原有历史；不覆盖已有工作区修改；不读取或修改真实题库用于测试。继续采用 Next.js、SQLite、现有 UI 和鉴权。

## 数据完整性

- [x] 题目更新区分省略、null、空数组，保留未提交字段。
- [x] 导入编辑后重新校验，失败保留草稿。
- [x] 统一题目指纹，兼容旧题库且不合并、删除历史题目。
- [x] 题目归档保留学习历史，默认抽题排除归档题。
- [x] 所有迁移可重复启动，新增表与字段不破坏已有记录。

负责模块：题目 API、导入 workflow、题库与详情、数据库结构及题目查询。

## 练习与复习

- [x] 本次会话返回恢复答案，回顾真正跳题；记录幂等、失败可重试。
- [x] 草稿可恢复，退出登录清理本地草稿。
- [x] 正确率只计算已判分题，主观题支持自评。
- [x] 学科、知识点、难度、题数与未做优先筛选。
- [x] 今日到期队列、错题掌握状态、薄弱知识点入口；保留答题流水。

负责模块：练习、错题、首页、学习记录与复习查询。

## 组卷与考试

- [x] 生成后固定题目快照，预览与导出一致，题量不足明确报错。
- [x] 手动选题可分页，组卷支持学科、知识点、难度。
- [x] 保存试卷与作答，刷新续答，服务端计时和统一交卷。
- [x] 答题卡与待检查标记，提交幂等，统一进入练习记录。

负责模块：试卷页面、试卷 API、试卷持久化及 Word 导出。

## 备份、内容与交付

- [x] 更新审计命中的依赖并验证兼容性。
- [x] SQLite 一致性备份、完整性校验和停服恢复工具，恢复前保留原库。
- [x] 设置页提供整库备份入口并说明与题目导出的区别。
- [x] 共用 Markdown、图片与数学公式渲染，保留纯文本显示。
- [x] AI 分步提示与错因分析，取消和失败状态明确；不调用真实模型服务验证。
- [x] 支持能可靠提取的来源页码；扫描件 OCR 保持按实际需求后置。
- [x] 回归测试、Lint、类型检查、生产构建、依赖审计及隔离浏览器流程验证。
- [x] 独立对抗式审查并复核，报告已验证项与剩余限制。

验收重点：修正导入错误后能提交；编辑不丢字段；返回重答不重复统计；未判分不算错误；同卷预览与导出题目相同；刷新恢复进度；重复交卷不重复写记录；备份包含新旧全部数据且恢复失败不损伤原库。

## 交付补充

- 浏览器使用隔离临时 SQLite 库，验证编辑、练习刷新续答、考试保存与交卷自评、导入错误修正及公式显示。
- 备份下载后恢复到另一临时库，题目、学习记录、试卷与作答数量一致。
- 公共仓库采用不带旧历史的代码快照，排除数据库、日志、环境变量、个人资料和内部代理记录；本地历史保留。
